# 禊カウンター

ふたりの「やらかし」（デートのキャンセル、飲み会など）を回数で記録し、決めた回数に達したら「禊」（償い）を求めるカウンターです。

例：飲み会に30回行ったら、奢りディズニー。

## 使い方

1. 「設定」で、ふたりの名前とルール（やらかしの内容・何回で禊か・禊の内容）を決める
2. 上のボタンで誰のやらかしかを選び、カードの **＋1** を押す
3. 回数に達するとカードが朱色になる。禊を終えたら **禊を済ませた** を押す（その回数分カウントが減る）

## 動かし方

`index.html` をブラウザで開くだけで動きます。ビルドは不要です。

## データの保存先

- claude.ai の Artifact として開いた場合：共有データベースに保存され、ふたりで同期されます
- それ以外（ローカルや GitHub Pages など）：そのブラウザの localStorage に保存され、端末ごとに別々の記録になります
